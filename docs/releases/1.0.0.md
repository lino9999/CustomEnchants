# CustomEnchants 1.0.0

Custom enchantments and equipment progression for Minecraft servers, created by **Lino**.

## Included

- 182 configurable enchantments and six rarity tiers (`COMMON`, `UNCOMMON`, `RARE`, `EPIC`, `MYTHIC`, `CELESTIAL`).
- Custom enchantment tomes, success/destruction rates, prerequisites, incompatibilities and slot limits.
- Enchanter shop, recycler and combiner workstations, and optional Vault money payments.
- Protection scrolls, unbinding scrolls, arcane dust, slot expanders, equipment cores, stat counters, soul crystals and name tag scrolls.
- Seven armor sets (`wayfarer`, `vanguard`, `wraith`, `warden`, `monarch`, `glacier`, `stormborn`), five special weapons and timed loadout kits.
- Combat, mining, farming, fishing, passive movement and defensive abilities powered by the CustomEnchants pipe-and-arrow DSL.
- Anvil application/merging, grindstone removal, enchanting-table tiers, weighted chest loot and villager trade rewards.
- `/customenchants` command hub with `/ce` and `/cenchants` aliases and `customenchants.*` permissions.
- English documentation, configuration reference and SpigotMC BBCode files.
- Pixel-art plugin icon.

## Installation

Download **CustomEnchants-1.0.0.jar**, place it in your server's `plugins` directory and restart. Configure the generated files and use `/ce reload`.

Target range: **Minecraft 1.21.11–26.3**, Spigot and Paper. Use **Java 21** for 1.21.11 and **Java 25** for 26.x. Folia is not supported. No required gameplay dependency; money purchases require Vault plus an economy provider.

## Downloads

- `CustomEnchants-1.0.0.jar`: ready-to-install plugin.
- `customenchants-icon.png`: pixel-art master icon for the resource listing.
- `spigot-description.bbcode`: resource description.
- `spigot-documentation.bbcode`: commands, permissions and configuration documentation.
